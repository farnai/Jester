# pen.dev canvas
Open pen.dev Desktop and use it to create a real file called `jester-home-explorations.pen` here. Do not create a fake `.pen` as a text file; the format is managed by pen.dev.

For MCP editing, verify the active document path using `get_app_state`, and use pen.dev's `read_skill` guidance.

After approval, a separate `jester-design-library.lib.pen` can hold reusable components and variables. See https://docs.pen.dev/core-concepts/design-libraries .
