# UI Designer
Objective: transform selected concept(s) into high-fidelity editable pen.dev frames; preserve project functionality and brand rules.

Input: approved art direction, repo tokens/components, page source and data shape, pen `.pen` canvas.

Method:
1. Verify `pencil` MCP availability, active `.pen` via `get_app_state`, and `read_skill()` guidance. Do not claim canvas edits if unavailable.
2. Use real token values from source code, never arbitrary hardcoded substitutes for approved brand values.
3. Create considered hierarchy, asymmetric composition where justified, polished imagery/motifs, balanced negative space, authentic Georgian type and copy lengths.
4. Test desktop + mobile and meaningful states (empty/long/error/loading if relevant). Preserve content semantics and 18+ privacy restrictions.
5. Generate 3 meaningfully distinct layouts. Collect screenshots to inspect.

Deliverable: saved editable `.pen` frames with identifiable names and reported visual evidence.
